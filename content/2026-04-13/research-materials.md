## 可直接写的选题角度（>=5 条）
- **选题 1：真正拉开 Agent 差距的，不是模型，是 memory + harness**
  - 目标受众：AI 开发者、技术负责人、重度工具用户
  - 核心观点：2026 年还把 AI 理解成聊天框的人，已经错过真正的产品主战场了。
  - 平台适配：X / 知乎
  - 为什么现在值得发：X 高互动、ainews、GitHub 热项都在指向同一条主线。

- **选题 2：Shopify 这一步，说明 AI 真开始接管后台了**
  - 目标受众：独立开发者、电商创业者、产品经理
  - 核心观点：未来最值钱的 AI，不是回答问题，而是能进入系统、承担责任、留下结果。
  - 平台适配：X / 小红书 / 知乎
  - 为什么现在值得发：这是最容易被普通人理解的 Agent 落地例子，传播面广。

- **选题 3：独立开发者最大的错觉，是以为自己缺点子，其实更缺分发系统**
  - 目标受众：一人公司、indie hacker、做 SaaS 的工程师
  - 核心观点：今天创业篮子最高频的不是“做什么”，而是“发去哪、怎么拿到前 100 个用户”。
  - 平台适配：小红书 / X
  - 为什么现在值得发：创业篮子里重复出现 launch list、获客 list，本身就是市场情绪证据。

- **选题 4：一人公司第二波红利，不是内容生产，而是把 workflow 做成资产**
  - 目标受众：solopreneur、自由职业者、效率党
  - 核心观点：NotebookLM、Claude Skills、浏览器自动化这些东西的共同点，不是工具酷，而是可以沉淀成长期复用的工作流。
  - 平台适配：小红书 / X / 知乎
  - 为什么现在值得发：效率圈现在最吃“模板化工作流”，不是泛泛工具推荐。

- **选题 5：霍尔木兹风险，为什么会影响科技公司、AI 创业和普通人的日常价格感知**

  - 核心观点：宏观变量不是金融圈专属，它会通过能源、航运、估值和风险偏好，直接改写科技叙事。
  - 平台适配：X / 知乎
  - 为什么现在值得发：X、知乎、微博都在同步发酵这条线，跨平台共振明显。

- **选题 6：AI 个人提效 10 倍，为什么公司还是赚不到钱？**
