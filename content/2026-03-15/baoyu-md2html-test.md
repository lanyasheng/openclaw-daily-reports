# OpenClaw 公众号排版测试

这是一个 **Markdown → HTML** 的测试样例。

## 为什么要做这个

因为微信公众号对 Markdown 原生支持很差，所以我们需要一层转换。

> 目标不是保留所有花哨 HTML，
> 而是把文章稳定地变成 **可粘贴、可展示、样式统一** 的内容。

### 清单

- 支持标题
- 支持粗体
- 支持引用
- 支持列表
- 支持代码块

const msg = 'hello wechat';
console.log(msg);
