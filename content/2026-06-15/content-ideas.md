## 创意 #1：Karpathy「别写 Prompt 了，写 Loop」

### AI 味诊断
- **AI 味等级**: 中低 — 题材本身偏技术，但核心观点"写 Loop 不写 Prompt"已经有反常识 hook，需要避免教科书式拆解 Karpathy 原话
- **问题点**: 容易写成"首先什么是 Loop Engineering，其次为什么重要，最后怎么实践"的三段式

### 标题候选

**人味版 A**（场景感）：
> 我花了 3 个月写 Prompt，Karpathy 一句话就让我白干了

**人味版 B**（代价/反差）：
> 同样是写代码，Loop 让我的 100 行 Prompt 变成了 30 行循环

**保守版**：
> 一个 shift+Enter 的思维转变：Karpathy 说的"写 Loop 不写 Prompt"到底在讲什么

### 核心信息
- 目标受众：AI 开发者 / Agent Builder / 对 AI 工作流感兴趣的技术人
- 核心观点：Prompt 微调是线性努力，Loop Engineering 是指数杠杆
- Hook 角度：用"我不知道我哪里错了，但我就是效率不对"的 developer pain 切入 → Karpathy 给出了答案
- 关键信息点：
  1. Karpathy 原话拆解：Loops over Prompts 不是技术术语，是思维模型
  2. Claude Code 创始人的呼应：他的日常工作就是设计循环
  3. 一个极简的例子：重复任务 → Prompt → 还是重复 → Loop
  4. 为什么这对普通开发者也是可迁移的 —— 不需要改代码，改的是方法

### 情绪价值
好奇（什么是 Loop Engineering）→ 实用（怎么从 Prompt 切到 Loop）→ 一点焦虑（我还在写 Prompt 别人已经写 Loop 了）

### 平台优化
- **X Thread**：5-7 条 thread，每条一个观点+一句行动建议。先放 Karpathy 原推截图，再讲自己的理解
- **小红书**：日记体。开头用"今天刷到 Karpathy 一条推……"带入，适合图文
- **知乎**：长文回答体。问题角度："Karpathy 说的 'Loops over Prompts' 在实际开发中怎么落地？"

### 传播预测
⭐⭐⭐⭐（4/5）
- 理由：Karpathy 自带流量 + "思维转变"类比性强 + 中文社区对 Loop Engineering 覆盖不足
- 时效窗口：本周内（热度刚起，中文解读少）

### 写作体裁
X：观点 Thread
小红书：日记体（有情景带入）
知乎：回答体

### 评论区首评

- **问题点**: 7.8M 爆款热度下很容易追投机角度而非技术角度

**保守版**：

### 核心信息
- 目标受众：对 AI+投资感兴趣的技术人 / 想用 AI 做量化的普通人

## 创意 #3：Anthropic 三件套「一张图讲清楚」

### AI 味诊断

**保守版**：
> 一图看懂 Claude 三件套：Chat / Code / Cowork 怎么选

### 核心信息
- 目标受众：在用/想用 AI 写代码的人、对效率工具感兴趣的人

**保守版**：

- 目标受众：大学生 / 职场早期 / 家有学龄子女的父母
