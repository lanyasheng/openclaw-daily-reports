## 跨 Agent 情报摘要

来源：`workspace-ainews/knowledge/daily/2026-04-12/morning-digest.md`

1. AINews 今天最强结论不是“又有新模型”，而是 Agent 生态正在围绕 Harness、Memory、Skill、可复现工作流快速收敛。
2. OpenAI Academy 开始推 Skills 教程页，说明大厂也在把重点从模型能力转向“稳定可复用工作流”。
3. LangChain 与开发者社区都在强化一个判断：Memory 的难点不是存，而是何时记、何时取、如何防污染，这本质上是编排层问题。
4. GitHub 热门项目里，hermes-agent、multica、Archon、Claude Code best practice 都在同一个方向上发热，说明 coding agent 正进入“工程化、可复现、可协作”阶段。
5. 对老板内容线的启发是，接下来更值得写的是“Agent 怎么真正进入生产”而不是“新模型参数又多了多少”。

## 可直接写的选题角度（>=5 条）

1. 选题：2026 年 AI Agent 的真正护城河，不是模型，是 Harness + Memory
- 目标受众：AI 开发者、技术管理者、Agent 创业者
- 核心观点：大家表面上在卷模型，底层上在卷状态管理、记忆治理、工具边界和可复现工作流。
- 平台适配：X / 知乎
- 为什么现在值得发：今天 X 和 AINews 两条线都在指向同一个结论，时机很整齐。

2. 选题：为什么 Anthropic 这波不是“模型赢”，而是“工作流赢”
- 目标受众：Claude Code 用户、开发者、AI 产品观察者
- 核心观点：从 Boris Cherny 到官方 Academy，Anthropic 在卖的其实是一整套开发者行为系统。
- 平台适配：X / 小红书
- 为什么现在值得发：社媒讨论已经从模型效果，转向具体怎么用、怎么学、怎么协作。

3. 选题：真正赚钱的 AI 创业，往往长得不像 AI 创业
- 目标受众：独立开发者、一人公司、想创业的工程师
- 核心观点：最值得做的不是最能发朋友圈的产品，而是最能替客户省时间、省钱、减人力的 boring workflow automation。
- 平台适配：X / 知乎
- 为什么现在值得发：今天最真实的样本不是 demo，而是农场商店发票自动化这种案例。

4. 选题：一人公司下半场，不是掌握 100 个 prompt，而是拥有 1 条自己的工作流
- 目标受众：独立创作者、技术型个体户、内容创业者
- 核心观点：Prompt 是零件，workflow 才是资产；会问问题的人很多，能把流程跑顺的人很少。
- 平台适配：小红书 / X
- 为什么现在值得发：X 上“one-person business + workflow ownership”是今天最稳定的轻共识。

5. 选题：市场现在最怕的，不是通胀，而是“未来感突然没了”
- 目标受众：投资者、宏观观察者、普通职场人
- 核心观点：消费者信心创历史低位，比单个 CPI 数据更能解释今天的风险厌恶。
- 平台适配：知乎 / X
- 为什么现在值得发：X、知乎、微博都出现了对同一条宏观情绪线的共振。

## 噪音过滤说明

1. 过滤了大量“免费课程 / cheat sheet / prompt 泄露”式 AI 营销帖，这类内容保存率高，但很多只是流量包装，缺少新信息。
2. 过滤了未经可靠来源佐证的加密狂热视频和“机构豪赌”类帖子，例如单源的巨额买入传言，这类帖情绪很强，但事实风险高。
3. 过滤了大量纯娱乐、明星、综艺、饭圈热词，尤其是微博热榜中的泛娱乐高位词，它们对老板账号的内容方向帮助极小。
