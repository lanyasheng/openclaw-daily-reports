## 🔗 AI news → 公司动作（3 条）

### 1. 微软 Agent Governance Toolkit → OpenClaw 权限模型升级启示
微软发布的 Agent Governance Toolkit 禁止 Agent 直接执行工具，必须通过策略引擎预检。OpenClaw 目前的 subagent 机制缺乏细粒度的策略层（如"哪些 Agent 可写文件/哪些需审批"）。这可以作为 OpenClaw 下一阶段安全架构的参考方向。

### 2. 复旦×通义 CUA 训练范式 + BotCircuits → OpenClaw MCP/Skill 调度优化
当前 OpenClaw 接入的 Skill 和 MCP 工具数量快速增长，Agent 的"工具选择困难症"正在成为瓶颈。复旦×通义的 CUA 训练范式（从训练阶段改进工具选择）和 BotCircuits（架构层面解决行为偏离）提供了两个互补方案：短期可借鉴 Headroom 上下文压缩降低 Token 成本，中期可评估工具选择策略的架构升级。

### 3. Anthropic Claude Code Dynamic Workflow → OpenClaw subagent 编排自进化
Claude Code 的 Dynamic Workflow 实现了一句话 prompt → 模型自编排子 Agent 群 → 自动验证。OpenClaw 当前的 subagent 仍然需要预定义 task + 带宽上限——Claude Code 的"模型自编排"方向是 subagent 机制的自然进化路径。
