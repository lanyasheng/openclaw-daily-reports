## 跨 Agent 情报摘要

1. AINews 今日最强主线不是“新模型更强”，而是 Agent runtime 正在升级。
- OpenAI 新一代 Agents SDK 被总结为“原生沙箱执行 + model-native harness + 长时任务”，竞争点上移到 runtime engineering。

2. 企业级 AI 关注点继续从“能不能做”转向“出错后能不能撤回”。
- Commvault 推出 AI 工作负载“Ctrl-Z”能力，说明 rollback / undo 正在变成企业级 Agent 基础设施。

3. Benchmark 叙事在升温。
- Hugging Face 与 IBM 对 VAKRA 的分析强调，不只是看 Agent 成功率，更要拆工具调用、失败恢复、稳定性短板。

4. 结论层面可浓缩成一句话：今天最值得写的 AI，不是新功能，而是“AI 开始像系统，而不再只是像聊天框”。
