### 选 2：Vercel CEO 一句话拆了 AI 圈的一堵墙——模型和 Agent 为什么必须分开

**300 字大纲**：

**开头**（反常识钩子）：我知道你的 IDE 里大概率装了 Claude Code 或 Codex。但 Vercel CEO Guillermo Rauch 说了一个反直觉的判断：Agent 不应该和模型绑定在一起。

**中间**（三段式）：
1. 当下的问题：每个 Agent 框架都在绑定自己的模型，换模型≈换全家桶。这就像当年手机厂商锁运营商，消费者很不爽。
2. 他的观点：Agent 应该是一个独立层，模型是插件。哪个模型性价比高就用哪个。ZCode 昨天发布、GLM 5.2 打价格战，都在印证这个方向。
3. 为什么重要：当模型价格趋近于零（AI Margin Collapse 分析），真正的价值在 Agent 编排、Skill 生态和数据层。Agent 平台的能力不再是谁家的模型最强，而是谁的编排最灵活。

**结尾**：
OpenAI 自己也意识到了这点——前天发布的 codex-plugin-cc 让 Claude Code 调用 Codex 做代码审查。竞品互通的格局，你见过几次？🔥
