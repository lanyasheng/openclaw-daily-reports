## 三情景概率加权框架

### 情景A: Goldilocks 延续 🌞 (概率: 45%)
**触发路径**: BOJ加息但指引鸽派 → 市场消化顺利 → FOMC持稳+沃什延续鲍威尔路线 → 中国数据有改善信号
**场景逻辑**: "通胀边际改善+降息预期+弱美元"的三重利好延续

| 维度 | 表现 |
|------|------|
| DXY | 维持99-100区间弱势 |
| 黄金 | $4,150-4,300 区间盘整 |
| A股 | 有色/资源链领涨，北向持续流入 |
| 港股 | 跟随EM修复，但受BOJ外溢影响 |
| 美股 | S&P维持7,300+，科技/AI主线延续 |
| **受益板块** | 黄金矿业、有色资源、港股中概、AI硬件 |
| **承压板块** | 银行(利率敏感)、消费(内需疲软) |

**失效条件**: BOJ鹰派超预期 / FOMC出现强烈鹰派信号 / 黄金单日跌>3%

---

### 情景B: BOJ冲击+鹰派转向 🌧️ (概率: 30%)
**触发路径**: BOJ加息至1.0%+鹰派前瞻 → 套息交易剧烈平仓 → USD/JPY暴跌 → EM资金外流 → FOMC沃什释放鹰派信号
**场景逻辑**: "日本资金回流+美元走强+风险偏好下行"的三重叠加

| 维度 | 表现 |
|------|------|
| DXY | 反弹至101-102 |
| 黄金 | 回调至$3,900-4,050（获利回吐+美元走强）|
| A股 | 北向净流出，成长股承压 |
| 港股 | **最大冲击** — 日元升值+南向资金分流 |
| 美股 | 科技股回调10-15%尤为可能（SpaceX抽血+宏观双重） |
| **受益板块** | 银行(息差扩大)、美元资产、防御型消费 |
| **承压板块** | 高杠杆科技股、港股中概、EM敞口、日元空头 |

**关键监测指标**:
- USD/JPY跌破125 → 触发情景升级
- 北向单日流出>80亿 → 确认EM资金外流
- 港股恒指单日跌>3% → 套息平仓冲击确认

**失效条件**: BOJ加息但日元不升 → 市场提前定价消化

| 维度 | 表现 |
|------|------|
| DXY | 99-101 窄幅震荡 |
| 黄金 | $4,100-4,300 区间波动 |
| A股 | 结构化行情，个股/板块alpha主导 |
| 港股 | 区间震荡，等待方向 |
| 美股 | 板块轮动，从科技/防御间切换 |

| **承压策略** | 高杠杆方向性押注、跨资产套利 |

**失效条件**: 任一央行事件超预期打破平衡
