## 5. 美国宏观传导分析

### 主线一：美伊冲突 → 能源安全 → 全球通胀
```
霍尔木兹紧张 → 原油供给风险溢价 → WTI 短期高位震荡
    ↓
美防长"不寻求交战"表态 → 油价回落 3.4% → 通胀预期短期缓解
    ↓
但若局势反复 → 油价再度飙升 → Fed 降息空间被压缩 → 成长股承压
```
**对 A 股传导**：
- 🔴 利空：高油价压制消费（航空/物流成本↑）、推高通胀预期压制 Fed 宽松
- 🟢 利好：能源板块（石油开采/油服）、黄金股、军工板块

### 主线二：特朗普 vs 鲍威尔 → 美联储独立性
```
特朗普"誓夺美联储控制权" → 市场质疑货币政策独立性
    ↓
长期：美元信用受损 → 黄金/非美货币受益
短期：政策不确定性 → 波动率上升
```
**对 A 股传导**：
- 🟢 利好：人民币国际化主题（"旧秩序裂痕"叙事）、黄金
- ⚠️ 中性偏多：外资流入中国资产的"替代效应"

### 主线三：美欧贸易摩擦 → 汽车关税
```
欧盟就特朗普汽车关税威胁回应"已做好各种准备"
    ↓
全球贸易碎片化 → 供应链重构
```
**对 A 股传导**：
- 🟢 利好：国产替代/自主可控链
- ⚠️ 关注：出口导向型制造业承压

### 主线四：AI 算力需求持续爆发
```
鸿海营收 +30% / AI 芯片市场 2027 年预计 1194 亿美元 / Anthropic ARR 首超 OpenAI
    ↓
AI 基础设施投资周期仍在加速
```
**对 A 股传导**：
- 🟢 利好：AI 算力链（海光/海康强势已验证）、服务器/光模块/PCB
