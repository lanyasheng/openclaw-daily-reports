## 三、过夜重要事件深度解读

### 事件1：美军发动"自由行动"击沉伊朗快艇，中东局势急剧恶化
- **来源**：华尔街见闻 07:10 / 财联社 06:00-07:37 多轮更新
- **事件链**：美军在霍尔木兹海峡附近发动军事行动击沉伊朗快艇 → 特朗普称美伊处于"迷你战争"状态 → 拒绝确认停火协议有效性 → 伊朗外长回应称"自由计划"是"僵局计划" → 德国确认派遣扫雷舰赴霍尔木兹 → 美情报评估显示本轮打击未进一步削弱伊朗核能力
- **为什么重要**：这是美伊冲突从"对峙"到"直接军事交火"的关键升级。霍尔木兹海峡承载全球约21%石油贸易量，任何封锁或干扰都将直接冲击全球能源供应链。
- **传导路径**：油价跳涨 → 通胀预期升温 → 美联储降息预期推迟 → 新兴市场货币承压 → A股能源板块受益、消费板块承压
- **持续性判断**：**高持续性（置信度70%）**。特朗普"从地球表面抹去"的措辞显示升级意愿，但美情报评估"未削弱核能力"暗示打击有限，存在"打打谈谈"的灰色地带。关键观察点：伊朗是否封锁海峡、OPEC是否增产。

### 事件2：Palantir Q1营收暴增85%，AI商业化进入加速期
- **来源**：华尔街见闻 05:29
- **事件**：Palantir Q1营收同比激增85%，上调全年指引远超预期。同日OpenAI、Anthropic被曝拉拢华尔街建合资公司。
- **为什么重要**：Palantir的爆发验证了AI从"概念投资"到"收入兑现"的拐点。AI基础设施→应用层的传导链正在加速。
- **传导路径**：AI应用商业化加速 → 全球AI投资周期延长 → 利好A股AI算力/AI应用/数据要素板块
- **持续性判断**：**高持续性（置信度75%）**。AI是确定性产业趋势，Palantir只是第一个财报验证者，后续微软/谷歌/亚马逊AI收入占比将持续提升。

### 事件3：橡树资本联席CEO警告市场"基本面风险遭严重低估"
- **来源**：华尔街见闻 05:24
- **事件**：Oaktree联席CEO公开表示市场定价"令人费解"，在宏观风险（地缘冲突、美联储独立性危机、贸易摩擦）高企的背景下，权益估值依然处于高位。
- **为什么重要**：顶级逆周期投资者发出警告，通常意味着市场情绪过于乐观。叠加特朗普施压美联储、司法部放弃上诉但无法解决央行独立性问题的背景，政策风险被市场定价忽略。
- **传导路径**：估值高位+风险被低估 → 一旦触发因素出现（如伊朗冲突升级、美联储被迫表态）→ 可能出现快速回调
- **持续性判断**：**中等持续性（置信度55%）**。橡树的警告有其道理，但市场可能继续"在乐观中定价"直到实质性利空出现。

### 事件4：美国3月工厂订单全面超预期，制造业复苏
- **来源**：华尔街见闻 04:47
- **事件**：美国3月工厂订单全面超预期，AI热潮推动制造业投资复苏。
- **为什么重要**：经济数据强劲一方面验证了"软着陆"叙事，另一方面也意味着美联储没有迫切降息理由——这与地缘冲突带来的通胀压力形成"滞胀风险"组合。
- **传导路径**：强经济数据 → 降息预期推迟 → 美元/美债收益率维持高位 → 新兴市场流动性承压
- **持续性判断**：**中等持续性（置信度60%）**。AI驱动的制造业投资有结构性支撑，但需观察是否被地缘风险抵消。

### 事件5：日元一度升至155区间，日本干预悬念再起
- **来源**：财联社 07:20
- **事件**：日元汇率一度升至155区间（即1美元兑155日元），日本财务相未证实干预猜测。
- **为什么重要**：155是日本此前干预的关键阈值。如果日本再次干预，将释放流动性——这部分流动性可能流入全球风险资产，但也可能加剧汇率波动。
- **传导路径**：日元波动 → 亚洲出口竞争力变化 → 影响A股出口链/航运板块
- **持续性判断**：**中等持续性（置信度50%）**。日本干预通常是脉冲式的，效果持续数日至数周。

**尾部风险**：霍尔木兹海峡通行受阻 → 全球油价冲击 $130-150 → 全球衰退概率飙升

- A股方面，海康威视 +4.25% 反映AI安防/边缘计算预期

**关键观察窗口**：

## 五、A股影响判断

### 整体评级：**中性偏谨慎**（置信度：55%）

**核心逻辑**：
1. 沪指早盘微涨0.11%，但结构分化明显——能源/军工受益地缘溢价，消费/新能源承压
2. 美债收益率跳升6.8bp至4.45%，中美利差维持高位，北向资金（已停更）预期承压
3. 港股表现强于A股：阿里 +4.52%、小米 +6.75%，反映外资对中国资产的配置意愿
4. 棕榈油/能源涨价传导至国内CPI预期，消费板块面临成本端压力

**正面因素**：
- 能源/军工/航运板块直接受益地缘升级
- AI主线有Palantir财报催化，海康威视等已反应
- 港股科技股强势可能传导至A股科技板块

**反面论据（风险）**：
- 若中东冲突进一步升级，全球risk-off可能波及A股（尤其外资持仓板块）
- 美债收益率持续走高压制成长股估值
- 茅台/宁德时代等权重股走弱，市场缺乏领涨主线
- 橡树资本警告"风险被低估"——估值高位+宏观逆风组合危险

**关注板块**：
- 🔶 能源（石油/天然气）：油价中枢上移直接受益
- 🔶 军工：地缘冲突催化，订单预期提升
- 🔶 航运：霍尔木兹风险溢价推升运价
- ⚠️ 消费：成本端通胀压力+风险偏好下降
- ⚠️ 新能源：利率上行压制估值+油价上涨削弱替代逻辑
