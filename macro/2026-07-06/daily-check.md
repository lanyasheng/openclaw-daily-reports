## 第三部分：过夜重要事件深度解读

### 事件 1：全球"黑色星期二"蔓延 — AI 板块集中抛售

**事件描述**：上周五（7/3），全球股市遭遇"黑色星期二"，韩股暴跌8%触发熔断，纳指期货一度跌2%，A股创业板跌逾4%，PCB、CPO等AI算力链领跌。周一亚盘早盘，纳指期货反弹逾1%。（来源：华尔街见闻 7/6 早报）

**为什么重要**：这是2026年以来最大幅度的AI主题集中抛售，核心诱因包括：① 市场对AI资本开支回报率的质疑加深（Capex放缓是否意味着行情终结已成讨论焦点），② 地缘扰动（炫光片封锁传言），③ 科技股估值已提前透支两年增长预期。

**传导路径**：美股AI → A股光模块/算力（中际旭创、新易盛） → 港股大模型双雄（百度/商汤） → 创业板 → 全市场情绪。上周五创业板跌逾4%可见传导极端。

**持续性判断**：短期（1-2周）仍有下探风险，但AI基本面（GPU需求、数据中心建设）并未逆转，属于"估值修正"而非"基本面逆转"。中际旭创已辟谣，关注该板块急跌后的反弹机会。

### 事件 2：OPEC+宣布8月再增产18.8万桶/日，美伊冲突预期降温

**事件描述**：OPEC+同意8月上调配额18.8万桶/日，自美伊战争爆发以来累计上调已近百万桶。同时特朗普表态：会在哈梅内伊葬礼上一次性干掉伊朗高层，但实际不会这么做，因为需要有人谈判。（来源：华尔街见闻 7/6 凌晨）

**为什么重要**：OPEC+从"减产保价"主动转向"增产保份额"，加之美伊冲突烈度预期下降，原油的地缘溢价正在快速消退。但油价下行对通胀是利好——美联储降息空间增加。

**传导路径**：OPEC+增产 → 原油供应增加 → WTI/布伦特下行 → 降低全球通胀预期 → 有利于美联储降息叙事 → 新兴市场资金流入。

**持续性判断**：原油短期承压至$65-68区间，但再往下美国页岩油成本支撑（$55-60）和OPEC+随时可调整政策构成底线。中期关注伊朗制裁真正解除后的增供冲击。

### 事件 3：央行六大行直连离岸交易，人民币定价权重塑

**事件描述**：中国六大行全面实现直连离岸交易，央行重塑人民币定价权机制。同时USD/CNY跌至6.77，人民币短期走强。（来源：华尔街见闻 7/5）

**为什么重要**：这是中国在人民币国际化进程中迈出的关键一步。六大行直连离岸意味着：① 央行对离岸人民币定价能力大幅提升，② 跨境套利空间压缩，③ 为人民币汇率弹性扩大创造条件。结合美元走弱，人民币具备阶段性升值的基础。

**传导路径**：央行直连离岸交易 → 汇率定价权增强 → 人民币走强预期 → 北向资金流入 A 股（利好蓝筹） → 汇率升值抑制出口但降低进口成本。

**持续性判断**：中期利好人民币资产重定价，但需要警惕人民币过快升值对出口企业（纺织、家电、电子代工）的利润挤压。

### 事件 4：黄金白银联袂暴涨，金银比快速压缩

**事件描述**：COMEX 黄金突破 $4,209.9（+2.36%），白银飙涨至 $63.51（+4.74%）。尽管高盛和德银接连下调金价预期（德银下调22%），市场仍强势上攻。（来源：Yahoo Finance / 华尔街见闻）

**为什么重要**：金银比（Gold/Silver Ratio）快速下降至66倍附近，通常意味着工业需求+投资需求双驱动的贵金属牛市第二阶段开启。白银在此轮上涨中弹性显著高于黄金，暗示市场不仅是对冲不确定性，也在追逐工业属性（光伏用银+AI电力需求）。

**传导路径**：美元走弱 + 美联储降息预期 + 地缘不确定性 → 贵金属避险需求上升 → 白银工业属性加杠杆 → 白银涨幅 > 黄金。

**持续判断**：看多黄金至$4,500（2026年底目标），白银在$65-$70区间有较强阻力。高盛/德银调降预期反而是市场逆向指标。主要风险：如果美联储意外偏鹰，贵金属将出现短期回调。

## 第四部分：宏观主线演绎

### 主线一：AI估值修正VS产业基本面——Gartner曲线正在重演

**最新演变**：上周的"黑色星期二"本质上是市场对AI板块过度炒作的Payback期。特斯拉7.49%的暴跌、Meta近5%的跌幅、英伟达回调1.39%——这些不是基本面的问题（GPU依然是供不应求），而是估值的问题。

**我们的观点**：
- 短中期（1-3个月）：AI算力链将承受一定压力，光模块、CPO等前期超额涨幅的品种可能面临进一步回撤。韩国设立100万亿韩元"未来应对基金"说明政府层面仍在加码半导体，但市场需要消化估值。
- 长期（6-12个月）：AI基础设施（数据中心、铜缆、电力）需求不会因季度回撤而改变。AI的本质是内存（HBM之父金正浩观点）——GPU真正工作的时间只有10%，意味着存储/互联/功耗管理的需求远未被定价。

### 主线二：黄金狂飙+美元走弱=全球储备货币体系再平衡

**最新演变**：美元指数停留在100.88低位，而黄金突破$4,200再创新高。美债收益率不降反升至4.49%——这与传统"避险买美债"的叙事背离。当前市场正在演绎"去美元化+再通胀"的双重逻辑。

**我们的观点**：
- 表面逻辑（避险买黄金）：不确定性驱动资金购入黄金
- 潜在线索（更关键）：美元指数快速下跌+各国央行持续增持黄金（尤其是中国央行），说明全球储备体系正在缓慢但确定地"去美元化"。6大行直连离岸交易正是这一进程的配套措施。
- 尾部风险：如果美联储被迫加息以控制通胀→对黄金短期利空，但中期来看"实际利率下降+信用货币贬值"的逻辑依然支撑金价上行。
