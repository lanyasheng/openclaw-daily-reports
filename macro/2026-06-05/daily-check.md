## 📰 过夜重要事件深度解读

### 事件1：博通(AVGO)暴跌超12%，AI芯片行情面临"预期天花板"

**事件摘要**：博通在季度财报基本符合预期的情况下暴跌超12%，单日蒸发约3000亿美元市值，引发AI基础设施板块全面下挫。《华尔街见闻》提出核心问题："AI芯片行情还剩多少安全边际？"（[来源](https://wallstreetcn.com/member/articles/3773906)）

**为什么重要**：博通是仅次于英伟达的AI芯片第二梯队核心标的，其暴跌打破了过去18个月"AI=买入"的惯性叙事。更关键的是传导链：
- 博通→光通信：Ciena业绩超预期且上调全年指引，股价仍跌超10%（说明市场已price in一切好消息）
- 算力硬件→数据中心：Jane Street拟自建数据中心应对算力短缺（[来源](https://wallstreetcn.com/articles/3773904)），说明基础设施需求仍然旺盛，但资本开支回报率开始被质疑

**传导路径**：AI预期过高 → 财报不够惊喜 = 利空 → AI板块估值修正 → 美科技板块整体承压 → 若扩散到NVDA，将触发系统性回调

**持续性判断**：短期至少需要1-2周消化。如果6月NVDA财报前AI板块持续承压，可能引发更广泛的科技仓位调整。ARM市盈率170倍（[来源](https://wallstreetcn.com/articles/3773898)）也是一个显著的高估值信号。

**事件摘要**：美联储官员最新表态称目前面临"保持耐心还是加息"的抉择，通胀仍是经济头号风险，AI目前未对经济数据产生实质性影响（[来源](https://wallstreetcn.com/articles/3773900)）。

**传导路径**：加息可能 → 美债收益率上行（4.48%）→ 美元指数企稳（99.43）→ 全球流动性收紧预期 → 新兴市场承压（韩元暴跌）

**持续性判断**：这是一场"长期博弈"，6月FOMC会议前不会有明确方向。市场利率预期将在"降息1次"和"不降息"之间来回摇摆，维持高波动。

### 事件3：韩元暴跌至2009年以来最低水平，韩国政治经济双危机

**事件摘要**：美元/韩元汇率突破1532.6，创2009年全球金融危机以来最低。韩政府已发出口头警告但韩元继续贬值（[来源](https://wallstreetcn.com/articles/3773895)）。

**为什么重要**：韩国作为全球经济"金丝雀"，其汇率急贬通常是全球风险偏好的先行信号。韩国受三重打击：(1) 尹锡悦弹劾后的政治真空期；(2) 出口依赖型经济受全球贸易不确定性打击；(3) 亚洲货币普遍承压的连锁反应。

**传导路径**：韩元贬值 → 亚洲新兴市场恐慌 → 外资流出亚洲股市 → 北向资金承压（虽已停发数据，逻辑仍然成立）

**持续性判断**：这不仅是韩国的问题，更是"特朗普关税2.0+强美元滞后效应"的典型体现。韩元可能在1600附近找到支撑，但在此之前亚洲市场情绪将持续承压。

### 事件5：Anthropic呼吁全球暂缓前沿AI研发，计算成本是IPO主因

**事件摘要**：Anthropic公开表示高昂的计算成本是推动其IPO的主因，并呼吁全球暂缓前沿AI研发（[来源](https://wallstreetcn.com/articles/3773907)）。

**为什么重要**：说明AI行业算力竞赛的"军备竞赛"模式正在遭遇商业变现的拷问。AI计算成本高昂支撑着卖铲子（NVDA/博通）的高估值，但如果AI应用侧（Anthropic/OpenAI）无法实现商业化回报，整个泡沫可能在某个拐点破裂。

**传导路径**：AI公司盈利压力 → 资本开支紧缩压力 → 算力需求下降 → 半导体去库 → 影响亚洲半导体供应链（韩国/台湾/日本）

**持续性判断**：短期不会出现AI资本开支断崖，但Anthropic的表态是AI行业"从叙事驱动到财务驱动"转变的标志性事件。
