### 传导路径 1: 油价→全球通胀预期→利率→成长股估值

```
伊朗升级 → 霍尔木兹风险 → WTI +15% (周)

    → 10Y收益率升破4.53%

        → 半导体/AI/纳斯达克承压（NQ -0.9%）
    → 美元反弹至101.16 
      → 北向资金有边际流出压力
```

**对A股板块传导：**
- ✅ **利好：能源（中石油+2.41%）、煤炭（陕西煤业+3.02%）** — 最直接受益，全球油价上涨A股能源联动
- ✅ **利好：黄金相关** — 黄金虽短期回调但避险需求中期支撑
- ⚠️ 谨慎：化工（化工ETF -3.69%昨日）— 油价推升原材料成本
- ⚠️ 谨慎：航空/交运 — 燃料成本上升
- ❌ 利空：半导体/AI — 韩国半导体恐慌跨市场传导，但昨日港股+台湾已出现逆转抵抗

### 传导路径 2: KOSPI 技术性熊市→亚洲资金重新配置

```
韩国半导体-22% → 韩国资金外流 
  → 部分回流中国/香港（昨日验证：恒指+2.5%）
  → 部分回流美国能源/金融
  → 资金未离开亚洲，而是sector rotation
```

**Key Insight:**
- 这是典型的"中国资产作为亚洲避风港"叙事
- 阿里巴巴+12.21%、恒指+2.5%验证了全球资金从韩国AI撤退后**未系统性减配亚洲**
- 如果今夜美国半导体（NVDA、AMD、MU）企稳或反弹，韩国恐慌可能触底 → 资金可能从中国回流韩国

### 传导路径 3: 地缘升级→全球risk-off→北向资金

```
伊朗局势升级 → 全球资金风险偏好下降 
  → 美元走强至101.16 
  → 离岸人民币压力6.8052 
  → 北向资金面临短期流出压力
```

**判断：** 北向资金今日可能是净流出，但只要幅度不超过30亿人民币，就属于正常波动。若北向净流出超50亿，需关注上证4,000的支撑力度。
