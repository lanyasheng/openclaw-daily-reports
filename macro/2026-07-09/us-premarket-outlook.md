## 四、美国宏观传导分析：伊朗冲突视角

### 传导链
```
美军袭击伊朗（布什尔核电站周边）
  ├─ 原油上涨通道 → 美国通胀预期升温 → 美联储降息路径受阻
  │    ↳ 影响A股: 石油化工（中石油/中石化）短期受益
  │    ↳ 影响A股: 交通运输、航空等成本承压
  ├─ 避险情绪升温 → 黄金/白银上涨 → 金矿股受益
  │    ↳ 影响A股: 山东黄金/紫金矿业（紫金预告上半年净利+68%）
  ├─ 中东供应链担忧 → 航运/保险成本上升
  └─ 风险偏好下降 → 北向资金或阶段性流出A股
       ↳ 但人民币走强可能部分对冲
```

### 地缘风险升级的尾部风险（置信度：中-高）
- 如果冲突升级为伊朗封锁霍尔木兹海峡 → WTI目标$85+，通胀预期急升
- 过去类似情境（2020年美伊冲突）：影响短期1-3天，市场快速消化
- **反面论据**: 美军已连续两天打击，市场已有定价。若今日无进一步升级，可能"买预期卖事实"
