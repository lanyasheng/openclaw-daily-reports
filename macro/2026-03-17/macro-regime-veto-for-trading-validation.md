# Macro Regime / Veto Framework for Trading Basket Validation

日期：2026-03-17
DRI：macro
用途：给 trading 的 basket 泛化验证补充**可复用的 regime / veto 框架**。本文**不重写交易结论**，只定义：
- 哪些历史窗口下，回测/验证结果可以参考
- 哪些宏观条件下，应一票否决或降权
- 一个可直接复用到后续回测报告的短模板

---

## 一、结论

### 1) 宏观总原则
对于 A 股 / 港股 / 中概联动 basket，**历史结果是否可参考，不取决于收益高低，而取决于测试窗口所处的宏观制度是否与当前相似**。

最少应分三类：
1. **流动性修复 / 低利率 Risk-On**：结果对成长/高弹性 basket 有较强参考价值
2. **通胀冲击 / 紧缩上行 Risk-Off**：对一般成长/高 beta basket 的历史结果**默认不外推**，除非策略本身就是防御/资源/空头/对冲型
3. **通胀回落 + 利率高位趋稳 / AI 风险偏好回升**：结果对质量成长、科技链、龙头 basket 有条件参考价值

### 2) 对 trading 的直接使用口径
- **可以参考的窗口**：
  - `2020-04 ~ 2021-12`：低利率 + 流动性修复 + 风险偏好修复
  - `2023-11 ~ 2024-07`：通胀回落 + 长端利率高位回落 + 波动率低位
- **默认一票否决窗口**：
  - `2022-03 ~ 2022-10`：高通胀 + 快速紧缩 + 高油价 + 高波动

> 解释：若 basket 是普通成长/高 beta/景气扩散型，拿 2022 年窗口跑出的差结果，不代表策略无效；同样，拿 2020-2021 或 2023-2024 跑出的高收益结果，也**不能**无条件外推到紧缩冲击环境。

### 3) Macro 对 basket 验证的边界定义
Macro 只给三件事：
- **regime tag**：当前更像哪个历史窗口
- **veto 条件**：哪些宏观状态出现后，历史结论不能外推
- **失效条件**：什么时候原先 regime 判定应撤销/降权

Macro **不负责**：
- 重新给交易结论
- 指定买卖点
- 评估个股 alpha

| 2022-03 ~ 2022-10 | 通胀冲击 / 紧缩 Risk-Off | CPI 同比均值 8.37%，WTI 均值 100.22，10Y 1.72%→4.10%，VIX 均值 26.67 | SPY -9.1%，QQQ -18.2% | **默认否决普通成长/高 beta basket 的外推**；仅对能源/防御/对冲/低久期策略有参考价值 |

### 2) 各窗口下“结果可参考”的条件与“一票否决”的条件

#### A. 窗口 A：2020-04 ~ 2021-12（低利率 + 流动性修复）
**适合参考的 basket 类型**
- 成长 / 高弹性 / 高景气扩散
- 海外科技风险偏好外溢受益链
- 宽信用或流动性修复受益板块

**结果可参考的前提（判断）**
- 长端利率**低位或温和抬升**，非失控上行
- 波动率处在**下行或低位稳定**阶段
- 大宗商品不是全面供给冲击主导
- 人民币/离岸人民币不处在快速贬值压力期

**一票否决（建议阈值，待 trading 回测校准）**
- `VETO_RATE_SHOCK`：美债 10Y 进入快速上冲段（如 20 交易日上行 >40bp，或绝对位进入高压区）
- `VETO_VOL_SPIKE`：VIX 升破 25 且持续 3 个交易日以上
- `VETO_OIL_SHOCK`：WTI >95 且油价主导市场叙事
- `VETO_CNH_STRESS`：USDCNH 快速走贬并触发 A/H 同步承压

**失效条件**
- 叙事从“流动性修复/盈利修复”切换为“通胀黏性/加息再定价”
- 海外科技上涨不再带来 A/H 风险偏好扩散，而变成单一美股拥挤交易

---

#### B. 窗口 B：2022-03 ~ 2022-10（高通胀 + 紧缩冲击）
**适合参考的 basket 类型**
- 防御 / 红利 / 能源 / 资源
- 对冲 / 低久期 / 低估值现金流型 basket

**对普通成长/高 beta basket 的口径**
- 此窗口的正负收益，**默认不作为普通成长 basket 的主外推依据**
- 原因不是“该窗口无效”，而是它代表的是**异常紧缩冲击制度**，与多数风险偏好修复窗口不同

**一票否决（高优先级）**
- `VETO_INFL_TIGHTENING`：CPI 高位黏性 + 长端利率上冲 + 风险资产同步承压
- `VETO_OIL_SUPPLY_SHOCK`：油价/能源供给冲击主导资产定价
- `VETO_USD_STRENGTH`：美元/离岸人民币压力同时上升，压制 A/H 成长风险偏好
- `VETO_HK_A_DECOUPLE_BREAK`：港股科技与 A 股成长同步失速，联动假设失效

**失效条件**
- 通胀见顶回落被确认
- 长端利率停止单边上冲
- VIX 从高位回落并重新稳定到低波动区间

---

#### C. 窗口 C：2023-11 ~ 2024-07（通胀回落 + 利率高位回落 + AI Risk-On）
**适合参考的 basket 类型**
- 质量成长 / 龙头科技 / 海外映射链
- 具备盈利韧性、估值弹性、外资偏好的 basket

**结果可参考的前提（判断）**
- 通胀处在回落/温和区间，而不是二次抬头
- 长端利率高位震荡或回落，而不是再进入加速上行段
- 波动率维持低位，拥挤交易未被宏观 shock 打断
- A/H 与美股科技链仍有方向一致性

**一票否决（建议阈值，待 trading 回测校准）**
- `VETO_REACCEL_INFLATION`：通胀二次上行并重启紧缩再定价
- `VETO_LONG_END_SELL_OFF`：10Y 再次出现高位快速上冲
- `VETO_VOL_REGIME_BREAK`：VIX 从 15-18 的低波动区间切入 >25
- `VETO_CHINA_FLOW_BREAK`：北向连续净流出 + A/H 关键成长链同步走弱

**失效条件**
- 市场从“软着陆/AI 扩张”叙事切回“再通胀/硬着陆”
- 龙头集中度过高，市场 breadth 明显恶化，导致 basket 历史分散收益不再可复制

## 三、给 trading 的可复用 veto 清单（短版）

> 用法：每次 basket backtest / validation 完成后，不改交易结论，先套这一层宏观闸门。

### 1) Regime Tag（必填）
- `REGIME_A_LIQUIDITY_REFLATION`
- `REGIME_B_INFLATION_TIGHTENING`
- `REGIME_C_DISINFLATION_AI_RISKON`
- `REGIME_X_MIXED/UNCLEAR`（若无法清晰归类，默认降权）

### 2) Veto Codes（建议先固定这些）
- `VETO_RATE_SHOCK`
- `VETO_VOL_SPIKE`
- `VETO_OIL_SHOCK`
- `VETO_INFL_TIGHTENING`
- `VETO_USD_CNH_STRESS`
- `VETO_NORTHBOUND_FLOW_BREAK`
- `VETO_HK_A_DECOUPLE_BREAK`
- `VETO_REGIME_UNCLEAR`

### 3) 使用原则
- 命中任一高优先级 veto：**该窗口结果不可直接外推**
- 未命中 veto 但 regime 不同：**只能降权参考，不能直接复用参数**
- regime 相似 + 无 veto：**可作为“可参考窗口”，但仍需让 trading 自己完成仓位/回撤检验**

```md

- Regime tag: <REGIME_A / REGIME_B / REGIME_C / REGIME_X>
- Reference window: <2020-04~2021-12 / 2022-03~2022-10 / 2023-11~2024-07 / custom>
- 是否可参考: <是 / 有条件 / 否>

### 结论
- 本次 basket 结果在宏观上属于：<可外推 / 仅可降权参考 / 默认不外推>

### 证据
- 利率状态：<低位修复 / 高位上冲 / 高位回落 / 不明确>
- 通胀状态：<回落 / 黏性高位 / 二次上行 / 不明确>
- 波动率状态：<低波动 / 冲击上行>
- 商品状态：<温和 / 油价冲击主导>
- 中国联动状态：<CNH稳定/承压；北向改善/恶化；A/H同步/背离>
- 命中 veto codes: <无 / 列表>

### 动作
- 对当前回测的处理：<保留为主样本 / 降权 / 从泛化样本剔除>
- 需要新增的对照窗口：<补 2022 紧缩段 / 补 2023-2024 低波段 / 补中国压力段>
- 需要 trading 补充的验证：<仓位敏感性 / 回撤约束 / 标的集中度 / 成交可实现性>
```

## 五、给 roundtable 的一句话口径

> **对 basket 泛化验证，Macro 的职责不是判断“赚不赚钱”，而是判断“这个历史窗口是否属于同一种宏观制度”；若不是同一种制度，结果默认不能外推。**

## 六、当前提醒（用于今天之后的复用）

> 当前外部环境（2026-03-17 抓取）显示：DGS10 4.28、2s10s +0.55、VIX 27.19、WTI 94.65。该组合更接近**高波动 / 油价偏高 / 利率仍有约束**，因此若 trading 在验证偏成长/高 beta basket，应优先检查是否已命中 `VETO_VOL_SPIKE` 与 `VETO_OIL_SHOCK`，避免把低波动 risk-on 窗口的结果直接套用到当前环境。

**置信度**
- 窗口划分：高
- veto 框架方向：中高
- veto 数值阈值：中（建议由 trading 用回测样本继续校准）
