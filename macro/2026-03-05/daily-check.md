## 第三部分：过夜重要事件深度解读

### 事件1：全球航运面临"双锁喉困局"——霍尔木兹+曼德海峡同时受阻
- **来源**: 华尔街见闻 07:28 | URL: https://wallstreetcn.com/member/articles/3766749
- **事件描述**: 不只是霍尔木兹海峡，曼德海峡也面临通行风险，全球航运正面临前所未有的双锁喉困局。
- **为什么重要**: 霍尔木兹海峡承担全球约20%石油运输（1700万桶/日），曼德海峡连接红海-苏伊士运河-地中海航线（全球12%贸易量）。两条咽喉要道同时受阻，意味着全球供应链面临系统性风险，而非局部冲突。
- **传导路径**: 
  ```
  双海峡封锁 → 航运绕行好望角 → 运价暴涨 + 运输时间延长2-3周 → 
  欧洲能源/商品供应紧张 → 输入性通胀上升 → ECB降息空间受限 → 
  欧元走弱 → 美元被动走强 → 新兴市场资本外流压力
  ```
- **持续性判断**: **趋势转折而非一次性冲击**。若伊朗局势持续升级（美国威胁报复、真主党持续袭击），封锁可能持续数周至数月。下一个关键观察点：美国是否启动战略石油储备（SPR）释放、北约是否介入护航。

### 事件2：普京称考虑主动给欧洲断气

- **事件描述**: 普京称考虑主动给欧洲断气，但强调俄依然是所有伙伴可靠的能源供应国。
