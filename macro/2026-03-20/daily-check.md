### 事件 1：以色列暂停空袭伊朗能源设施——战术调整而非战略转向

- **事件描述**: 响应特朗普呼声，以色列总理称将暂停空袭伊朗能源设施，但卡塔尔称伊朗袭击已破坏 17% LNG 产能。内塔尼亚胡仍寻求伊朗"政权更迭"并暗示或有地面行动。
- **为什么重要**: 市场可能误读为"局势缓和"，但这是战术暂停而非战略转向：(1) 17% LNG 产能破坏已实质性发生，修复需 1-2 周；(2) 内塔尼亚胡"政权更迭"目标未变；(3) 地面行动暗示冲突可能升级而非降级。**关键判断**: 油价已定价实质性供应冲击，难回$100 以下；若地面行动确认，可能测试$120-130。
- **传导路径**: 
  ```
  暂停空袭 → 市场误读为缓和 →
  油价短暂回调 →
  但产能破坏已发生 →
  1-2 周供应缺口确认 →
  油价重新上行
  ```
- **持续性判断**: **中期影响（2-4 周）**。关键验证点是设施修复进度 + 以色列是否确认地面行动。置信度：高。

  ```
  油价高位 →
  欧洲能源进口成本上升 →
  核心通胀反弹 →
  ECB 政策两难（抗通胀 vs 保增长）→

  资本流出欧洲
  ```

- **持续性判断**: **中期影响（1-3 个月）**。关键验证点是欧洲 3 月/4 月通胀数据。置信度：中高。
