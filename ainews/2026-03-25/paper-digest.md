### 1. 从静态模板到动态运行时图：LLM Agent 工作流优化综述
**URL:** https://arxiv.org/abs/2603.22386v1  
**发布:** 2026-03-23 | **分类:** cs.AI, cs.CL

**解读:** 这篇综述系统梳理了 LLM 工作流优化的最新进展。传统 Agent 工作流依赖静态模板，而新趋势是构建动态运行时图——在执行过程中根据中间结果自适应调整调用顺序。论文覆盖了工作流设计的核心要素：LLM 调用编排、信息检索、工具使用、代码执行、记忆更新和结果验证。对于 OpenClaw 这类 Agent 编排平台，动态图意味着可以更灵活地处理复杂任务，减少硬编码的分支逻辑，提升 Agent 的自适应能力。

### 2. Reasoner-Executor-Synthesizer：可扩展的 O(1) 上下文窗口 Agent 架构
**URL:** https://arxiv.org/abs/2603.22367v1  
**发布:** 2026-03-23 | **分类:** cs.IR, cs.AI

**解读:** 针对 RAG 系统中上下文窗口线性增长导致的幻觉风险和 token 成本问题，论文提出 RES 三元架构：Reasoner 负责问题分解，Executor 负责工具调用，Synthesizer 负责结果整合。关键创新是保持静态 O(1) 上下文窗口——无论检索多少文档，每个组件只接收固定长度的摘要输入。这对于长文档问答、大规模知识库检索场景极具价值，可显著降低 token 消耗并减少长上下文引发的幻觉。

### 3. 基于推理痕迹表示的多 Agent 系统高效故障管理
**URL:** https://arxiv.org/abs/2603.21522v1  
**发布:** 2026-03-23 | **分类:** cs.SE, cs.AI

**解读:** 随着多 Agent 系统复杂度提升，故障诊断成为瓶颈。论文提出用"推理痕迹表示"（Reasoning Trace Representation）来捕获 Agent 决策过程的关键状态，当系统失败时可快速回溯定位问题源头。该方法将 Agent 的内部推理过程结构化存储，支持故障后的自动恢复和重试策略调整。对于生产级多 Agent 应用（如自动化工单处理、代码审查流水线），这是提升系统可靠性的关键技术。

### 4. 模型优先推理 LLM Agent：通过显式问题建模减少幻觉
**URL:** https://arxiv.org/abs/2512.14474v1  
**发布:** 2025-12-16 | **分类:** cs.AI

**解读:** 针对 LLM 在多步规划任务中的约束违反和解决方案不一致问题，论文提出"模型优先"方法——Agent 在执行前先构建显式的问题状态表示（类似经典 AI 规划中的状态空间），而非依赖隐式的 Chain-of-Thought 追踪。实验显示该方法在复杂约束满足任务上显著降低幻觉率。这对需要高可靠性的 Agent 应用（如法律文档分析、医疗诊断辅助）有重要参考价值。

### 5. PaperVoyager：用视觉语言模型构建交互式论文网页
**URL:** https://arxiv.org/abs/2603.22999v1  
**发布:** 2026-03-24 | **分类:** cs.CL

**解读:** 现有论文 Agent 大多输出静态摘要或幻灯片，无法支持技术论文的深度交互探索。PaperVoyager 利用视觉语言模型将论文转换为交互式网页：读者可点击图表查看数据源、悬停公式查看推导过程、选择段落生成不同粒度的解释。这对于学术阅读工具、技术文档平台是重要升级方向，让论文从"被动阅读"变为"主动探索"。

### 7. TRACE：地震学中自主物理推理的多 Agent 系统
**URL:** https://arxiv.org/abs/2603.21152v2  
**发布:** 2026-03-22 | **分类:** physics.geo-ph, cs.AI

**解读:** 从间接地球物理观测中推断地震序列的物理机制极具挑战性。TRACE 系统用多 Agent 协作完成这一任务：不同 Agent 负责数据预处理、特征提取、物理模型拟合、结果验证。关键创新是 Agent 间共享"物理一致性约束"，确保最终解释符合地震学基本原理。这是科学发现 Agent 的典型案例，展示了多 Agent 系统在专业科学领域的落地路径。
