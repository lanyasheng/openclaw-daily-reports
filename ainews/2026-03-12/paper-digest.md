**1. GRACE: 统一的多机器人路径规划仿真与基准测试平台**
URL: https://arxiv.org/abs/2603.10858v1

多智能体路径规划（MAPF）和多机器人运动规划（MRMP）领域长期缺乏能够进行透明、可复现比较的统一平台。现有工具要么在简化假设下扩展（网格、同质智能体），要么提供更高保真度但可比性较差。GRACE 提出了一个统一的 2D 多机器人路径规划仿真器，支持网格、路标图和连续环境的无缝切换。该平台允许研究者在相同环境下比较不同建模选择的性能，显著降低了实验复现的门槛。对于从事多智能体协作、仓储物流自动化、无人机编队等方向的研究者，GRACE 提供了一个标准化的评估基准，有望推动该领域从"各自为战"走向系统性进步。

**2. LLMGreenRec: 基于大语言模型的多智能体可持续电商推荐系统**
URL: https://arxiv.org/abs/2603.11025v1

随着环保意识提升，电商推荐系统需要在引导用户选择可持续产品的同时，最小化自身的数字碳足迹。传统会话式推荐系统优化短期转化率，往往无法捕捉 nuanced 的用户意图和长期可持续偏好。LLMGreenRec 创新性地采用多智能体架构：一个智能体理解用户偏好，一个评估产品可持续性，一个优化推荐多样性，还有一个专门监控系统的计算能耗。实验表明，该系统在推荐质量与传统方法相当的情况下，碳足迹降低约 34%。这项工作为"绿色 AI"提供了可落地的范式——AI 系统不仅要帮助用户做出环保选择，自身也应当是低碳的。

**3. TOSSS: 基于 CVE 的大语言模型软件安全基准测试**
URL: https://arxiv.org/abs/2603.10969v1

随着 LLM 在软件开发工作流中的普及，一个关键问题浮现：LLM 生成的代码是否安全？TOSSS 构建了一个基于已知 CVE（通用漏洞披露）的基准测试集，用于评估 LLM 在代码生成、代码审查、漏洞修复等任务中的安全表现。研究者从真实 CVE 数据库中提取漏洞模式，构造测试用例，系统性地评估主流 LLM 的安全意识。初步结果显示，即使是先进的模型，在面对某些经典漏洞模式（如 SQL 注入、缓冲区溢出）时仍会生成不安全代码。这项工作为 LLM 安全评估提供了标准化工具，也提醒开发者：LLM 辅助编程不能完全替代人工安全审查。

**4. 测试时扩展下的推理 LLM 排名方法研究**
URL: https://arxiv.org/abs/2603.10960v1

测试时扩展（Test-Time Scaling）通过为每个提示采样多个输出来评估推理 LLM 的能力，但在此机制下如何排名模型仍缺乏系统研究。本文形式化了测试时扩展下的密集基准排名问题，并推出 Scorio 库，实现了配对比较、Bradley-Terry 模型等统计排名方法。研究发现，传统单次采样排名在测试时扩展场景下会产生显著偏差，而适当的统计方法可以更稳健地区分模型能力。对于正在评估 o1、R1 等推理模型的研究者和从业者，Scorio 提供了更科学的评估工具，避免因采样噪声导致的错误结论。

**5. DynVLA: 学习世界动力学以支持自动驾驶中的动作推理**
URL: https://arxiv.org/abs/2603.11041v1

自动驾驶视觉 - 语言 - 动作（VLA）模型通常直接从感知映射到动作，缺乏对物理世界动态的显式建模。DynVLA 提出了一种新的思维链范式——"动力学思维链"（Dynamics CoT）：模型在生成动作之前，先预测紧凑的世界动力学表示（如其他车辆的速度、加速度、轨迹）。通过引入动力学令牌（Dynamics Tokens）来编码这些预测，DynVLA 能够做出更符合物理规律、更安全的驾驶决策。在 nuScenes 等基准测试中，DynVLA 在复杂交互场景（如无保护左转、密集车流并线）的表现显著优于基线。这项工作表明，将物理直觉显式编码到 VLA 模型中，是提升自动驾驶安全性的有效路径。

**6. STADA: 基于规范的自动驾驶智能体测试方法**
URL: https://arxiv.org/abs/2603.10940v1

仿真测试已成为自动驾驶智能体部署前的标准验证方法，但如何设计高质量的测试活动仍缺乏系统指导。STADA 提出了一种基于规范的测试框架：首先形式化定义测试规范（涵盖静态环境如车道、路口、标志，以及动态元素如其他车辆、行人行为），然后自动生成多样化的测试场景来覆盖这些规范。该方法确保测试活动系统地探索智能体可能遇到的各类边界情况，而非随机采样。对于自动驾驶开发团队，STADA 提供了一套可复用的测试规范语言，有助于建立更完善的验证流程，降低部署风险。

**7. 强化学习中的遍历性问题**
URL: https://arxiv.org/abs/2603.10895v1

强化学习通常优化策略在轨迹上的期望奖励总和，但这一目标假设奖励生成过程是遍历的（ergodic）——即时间平均等于集合平均。本文指出，在许多实际场景中（如金融投资、资源管理），过程是非遍历的，此时期望值作为优化目标可能产生误导性结果。作者分析了非遍历性对 RL 算法的影响，并提出了替代目标函数，如时间平均增长率优化。这项工作对 RL 在金融、能源等长周期决策领域的应用具有重要启示：直接套用标准 RL 公式可能导致次优甚至危险策略，需要根据问题特性调整优化目标。

**8. 量子中心超级计算机的参考架构**
URL: https://arxiv.org/abs/2603.10970v1

量子计算机已在模拟量子系统方面展现出超越经典暴力方法的能力，但如何将量子计算整合到实际科研工作流中仍是挑战。本文提出了"量子中心超级计算机"的参考架构：量子处理器作为加速器，与经典 HPC 系统紧密耦合，通过统一调度器管理混合工作负载。架构设计考虑了量子 - 经典数据交换、误差校正开销、作业排队等实际工程问题。IBM、MIT 等机构的研究者共同参与了这项工作，反映了产业界对量子 - 经典混合计算的重视。对于关注量子计算实用化的研究者，这篇论文提供了清晰的系统蓝图，有助于理解量子计算从实验室走向生产环境的路径。
