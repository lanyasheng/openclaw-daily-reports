**影响评估：** P1 — 监管宽松化利好行业短期发展，但缺乏统一安全标准可能延缓企业级 AI 部署的信任建立。

### 2. Microsoft 发布 Fara1.5 浏览器智能体家族（4B/9B/27B），超越 OpenAI Operator 和 Gemini 2.5
[MarkTechPost](https://www.marktechpost.com/2026/05/22/microsoft-releases-fara1-5-a-family-of-browser-computer-use-agents-4b-9b-27b-that-outperform-openai-operator-and-gemini-2-5-computer-use-on-online-mind2web/)

Microsoft Research 发布了 Fara1.5 系列浏览器计算机使用智能体，包含 4B、9B 和 27B 三个规模。其中 Fara1.5-27B 在 Online-Mind2Web 基准上达到 72% 得分，超越了 OpenAI Operator 和 Gemini 2.5 Computer Use。

这意味着浏览器自动化智能体正从"能用"走向"好用"。多尺寸模型策略使企业可以根据成本和性能需求灵活选择。对于 MCP 生态和 Agent 工作流而言，浏览器级操作能力的提升将直接推动自动化场景落地。

**影响评估：** P1 — 浏览器智能体能力跃升，直接利好 MCP/Agent 工具链生态，需关注其对 OpenAI Operator 的市场挤压。

### 3. Google 再次 3 倍提升 Gemini 配额，Antigravity 使用量激增
[Nitter / Demis Hassabis](https://nitter.net/_mohansolo/status/2057656550286885284)

Google DeepMind CEO Demis Hassabis 宣布再次将 Gemini 付费计划的每周配额提升 3 倍，同时重置所有付费计划的配额限制。此前 Antigravity 工具的使用量已增长 3 倍，用户频繁触及限额。

这反映出 AI 编码工具的使用需求远超供给预期。Google 在 OpenAI Codex 和 Anthropic Claude Code 的激烈竞争中，通过激进扩容策略争夺开发者心智。但配额一再放宽也引发对成本可持续性的担忧。

**影响评估：** P2 — 短期利好开发者体验，但长期需观察 Google 能否在免费扩容与盈利之间找到平衡。

### 4. Anthropic Boris 承认：最挑剔的用户反而最离不开 Claude
[InfoQ 中文](https://www.infoq.cn/article/SuTZe24r2UTRkR82ODl9)

Anthropic 的 Boris 公开承认，那些对限速、限流抱怨最激烈的用户，实际上是最深度依赖 Claude 的用户群体。这一表态揭示了 AI 产品中的一个经典悖论：高价值用户往往也是最高频的"抱怨者"。

这背后反映的是 AI 编码工具从"尝鲜"走向"刚需"的转折点。当用户的工作流深度绑定某个 AI 工具后，任何性能波动都会引发强烈反馈。Anthropic 需要在扩容能力和产品定价之间做出更精细的平衡。

**影响评估：** P2 — 产品策略信号，表明 AI 编码工具的粘性正在快速增强，竞争将从"功能比拼"转向"稳定性比拼"。

### 5. 李飞飞发布空间智能 ImageNet 基准，具身智能评测进入新阶段
[量子位](https://www.qbitai.com/2026/05/422738.html)

李飞飞团队推出了专门用于评测具身空间智能的新基准，被称为"空间智能的 ImageNet"。这一基准填补了具身 AI 领域标准化评测的空白，为机器人、自动驾驶等空间智能应用提供了统一的衡量标准。

ImageNet 曾推动计算机视觉的爆发式发展，空间智能基准的推出可能产生类似效应。它将加速具身 AI 模型的迭代速度，并帮助投资者和开发者更清晰地评估不同方案的技术水平。

**影响评估：** P1 — 具身 AI 基础设施级别的事件，可能催生新一轮基准竞赛，关注相关开源项目和参赛团队。

### 6. DeepSeek Code 即将发布，融资 700 亿，ACM 金牌大神崔添翼挂帅
