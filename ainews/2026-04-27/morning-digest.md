### 1. OpenAI 再次关停独立 Codex 编码模型，能力并入 GPT-5.5
[The Decoder](https://the-decoder.com/openai-kills-its-dedicated-coding-model-codex-again-folding-it-into-gpt-5-5/)
OpenAI 再次终止了独立的 Codex 编码模型，将其能力直接整合到主模型 GPT-5.5 中。GPT-5.5 承诺更强的 agentic 编码能力和更低的 token 消耗。这意味着 OpenAI 正在统一模型产品线，编码能力不再作为独立 SKU 存在。
**影响评估：** 🔴 高 — Codex CLI / API 用户需尽快迁移至 GPT-5.5，Agent 编码工作流可能迎来架构调整。
