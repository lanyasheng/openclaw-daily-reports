## **新增新闻**（5 条）

**1. Moltty：持久化 AI 编码会话管理工具** [Moltty](https://moltty.com/)
新推出的 Moltty 解决 AI 编码会话碎片化问题，提供组织化、持久化的会话管理能力。开发者可在中断后快速恢复上下文，避免重复提示和状态丢失。这是 AI 编码工作流基础设施的重要补充。

**2. deepagents-cli 0.0.28 发布：视频多模态支持** [Twitter - LangChain](https://nitter.net/masondrxy/status/2029702660979646769#m)
Harrison Chase 团队发布 deepagents-cli 新版本，新增视频多模态输入支持、模型选择器 Tab 自动补全、斜杠命令模糊搜索。这是 LangChain 生态向多模态 Agent 迈进的关键一步，视频理解能力将打开新的应用场景。

**3. 高德发布大模型驱动视觉认知步行导引系统** [量子位](https://www.qbitai.com/2026/03/384557.html)
高德地图推出全球首个由大模型驱动的视觉认知步行导航系统，实现"可视、可感、可用"的空间智能应用。系统能理解复杂环境并生成自然语言指引，标志着 LLM 从文本向物理空间感知的跨越。

**4. Claude Code 生产级代码实践指南** [Towards Data Science](https://towardsdatascience.com/how-to-create-production-ready-code-with-claude-code/)
新发布的实战指南系统讲解如何用 Claude Code 编写生产级代码，涵盖测试驱动、代码审查、部署流程等关键环节。这反映了 AI 编码工具从"能写代码"到"写好代码"的成熟度提升。

**5. Qwen-Agent GitHub 热榜：通义千问 Agent 框架** [GitHub](https://github.com/QwenLM/Qwen-Agent)
阿里 Qwen 团队开源的 Agent 框架今日登上热榜，支持 Function Calling、MCP、代码解释器、RAG 和 Chrome 扩展。这是国产大模型在 Agent 生态布局的重要信号，与 OpenAI Skills 形成对标。
