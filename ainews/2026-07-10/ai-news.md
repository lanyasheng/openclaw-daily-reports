# AI News Digest — 2026-07-10

## 🔥 Headline: OpenAI Launches GPT-5.6 Family (Sol, Terra, Luna)

OpenAI released the **GPT-5.6 family** for general availability following a limited preview.

### Three Models:
- **Sol** — Flagship frontier model, new SOTA
- **Terra** — Balanced model for everyday work
- **Luna** — Most cost-efficient model

### Key Benchmarks:
- **Agents' Last Exam**: Sol @ 53.6 — beats Claude Fable 5 (adaptive reasoning) by **13.1 points**
- **Artificial Analysis Coding Agent Index**: Sol @ 80 — **2.8 points above Fable 5**, using <50% tokens, <50% time, ~⅓ less cost
- **Terminal-Bench 2.1 & DeepSWE**: New SOTA on complex CLI workflows and long-horizon engineering

### Key Features:
- **Ultra mode**: Multi-agent orchestration across parallel workstreams for complex tasks
- **Programmatic Tool Calling**: Models can write/run lightweight programs that coordinate tools
- **Improved intent understanding**: Infers user goals without explicit step-by-step
- **Shorter prompts recommended**: Minimal prompts improved scores 10-15% while reducing tokens 41-66%
- **Original image detail preserved**: No patch-budget resizing
- New safeguards with red-teaming and automated testing

### Developer Notes:
- Avoid generic brevity instructions (model is more sensitive than GPT-5.5)
- "Be concise" type prompts may degrade quality
- Control warmth doesn't meaningfully improve output
