**1. 中国批准全球首个侵入式脑机接口芯片：Neuralink 被中国团队超车**

[来源：MIT Technology Review](https://www.technologyreview.com/2026/06/01/1138133/china-world-first-brain-chip/)

上海脑虎科技（Neuracle）联合清华大学研发的侵入式脑机接口芯片 NEO 正式获中国国家药监局批准上市，成为全球首个获批进入临床使用的侵入式 BCI 产品，适用范围为 18-60 岁因脊髓损伤导致四肢瘫痪但保留部分上肢残余功能的患者。NEO 仅 8 个传感器放置于硬脑膜上方（而非穿透皮层），相比 Neuralink 的 N1 芯片创伤更小、长期信号衰减更低，且受益于中国对 BCI 产业的快速审评通道。已完成的 36 例临床试验中，首例患者董先生在术后第 9 天即实现不使用机械手套抓握球体。**影响评估：高** — 脑机接口从实验室走向监管批准，AI Agent 正在突破纯软件边界进入神经交互领域，这是具身智能的终极形态之一。

## 📊 趋势分析（4条）

**趋势一：BCI+AI —— Agent 的物理世界接口正在打开**

中国 NEO 芯片获批是全球 BCI 产业的里程碑事件。脑机接口 + AI Agent 的组合意味着：未来的 Agent 指令可能不再局限于文本/语音输入，而是直接来自神经信号。虽然消费级应用还很遥远，但医疗康复场景的快速推进正在为更广泛的"思维-机器"交互铺路。AI Agent 的定义边界正在从纯软件扩展到人体增强。

**趋势二：Agent 基础设施链全线开花，每个环节都在长出专门产品**

从文档处理（markitdown）到记忆引擎（supermemory）到文件搜索（fff）到设计语言（impeccable）到跨平台 Skill（compound-engineering-plugin）到 Meta-Skill（harness）——Agent 基础设施的每个细分环节都在长出独立产品并快速获得社区验证。Agent 开发正在从手工作坊式的 Prompt 拼装走向标准化的组件式拼装，生态成熟度正在快速提升。

**趋势三：AI 社会许可危机正在年轻群体中加速蔓延**

FT 的年轻人态度调查、哈佛"摧毁 AI"演讲、heretic 审查移除工具——三件事叠加构成完整链条：舆论反对 → 精英背书 → 工程反制。AI 行业需要正视这不是"一小撮人的抱怨"，而是代际性的态度逆转。对技术团队而言，这意味着未来的 AI 产品设计需要更多考虑透明度、可控性和伦理合规，而非单纯追求能力上限。

**趋势四：多 Agent 协作在垂直场景加速成熟**

TradingAgents（8.1 万星）代表了多 Agent 架构在金融领域的规模化验证，而 harness（Meta-Skill 生成 Agent 团队）代表了 Agent 编排的通用化方向。两个项目同时高增长说明：多 Agent 协作已经从"可以这样做"演进到"这是标准做法"，垂直场景的 Agent 编排框架正在成为新的产品品类。
