### 1. SocialGrid: 具身多智能体系统的规划与社交推理基准
**URL:** https://arxiv.org/abs/2604.16022v1  
**发布:** 2026-04-17 | **分类:** cs.AI, cs.LG, cs.MA

**解读:** 随着大语言模型从文本处理器转向自主智能体，评估其在具身多智能体环境中的社交推理能力变得至关重要。作者推出 SocialGrid，这是一个受《Among Us》游戏启发的具身多智能体环境，用于评估 LLM 智能体在规划、任务执行和社交推理方面的能力。该基准填补了多智能体协作与竞争场景下系统性评估的空白，对开发更智能的协作型 AI 代理具有指导意义。

### 2. WebUncertainty: 双层级不确定性驱动的自主 Web 智能体规划与推理
**URL:** https://arxiv.org/abs/2604.17821v2  
**发布:** 2026-04-20 | **分类:** cs.AI

**解读:** 现有自主 Web 智能体在处理涉及动态交互和长周期执行的复杂任务时，常因僵化的规划策略而失败。本文提出 WebUncertainty 框架，通过双层级不确定性量化（状态不确定性和动作不确定性）驱动智能体的规划与推理过程。该方法使智能体能够在执行过程中动态调整策略，显著提升复杂 Web 任务的成功率。对于构建更鲁棒的浏览器自动化智能体具有实用价值。

### 3. MASS-RAG: 多智能体合成检索增强生成
**URL:** https://arxiv.org/abs/2604.18509v2  
**发布:** 2026-04-20 | **分类:** cs.CL

**解读:** 当检索到的上下文存在噪声、不完整或异构时，单一生成过程往往难以有效整合证据。作者提出 MASS-RAG，利用多个智能体并行生成候选答案，然后通过合成机制融合不同视角的证据。该方法在噪声检索场景下显著优于传统 RAG，为提升 RAG 系统在真实世界数据质量参差不齐环境下的鲁棒性提供了新思路。

### 4. Model-First Reasoning LLM Agents: 通过显式问题建模减少幻觉
**URL:** https://arxiv.org/abs/2512.14474v1  
**发布:** 2025-12-16 | **分类:** cs.AI

**解读:** LLM 在复杂多步规划任务中常出现约束违反和解决方案不一致的问题。现有策略如 Chain-of-Thought 和 ReAct 依赖隐式状态追踪，缺乏显式问题表示。本文受经典规划领域启发，提出"模型优先"推理框架，要求智能体在执行前先构建显式的问题模型。实验表明该方法显著降低了幻觉率，提升了规划任务的一致性。对构建高可靠性 AI 代理系统具有参考价值。

### 5. LongCoT: 长周期思维链推理基准测试
**URL:** https://arxiv.org/abs/2604.14140v1  
**发布:** 2026-04-15 | **分类:** cs.LG, cs.AI

**解读:** 随着语言模型被越来越多地部署于复杂自主任务，其在长周期内的准确推理能力变得关键。本文推出 LongCoT，一个可扩展的长周期思维链（CoT）推理基准，包含 2000+ 需要多步推理的问题。基准测试揭示了当前模型在长程推理中的系统性缺陷，为评估和改进模型的长周期规划能力提供了标准化工具。对 Agent 长任务执行能力的评估具有指导意义。

### 6. WorldDB: 具有本体感知写入时 reconcilation 的向量图世界记忆引擎
**URL:** https://arxiv.org/abs/2604.18478v1  
**发布:** 2026-04-20 | **分类:** cs.AI, cs.CL

**解读:** 持久化记忆是将无状态聊天机器人与长周期智能体系统区分开来的瓶颈。传统 RAG 在扁平向量存储上碎片化事实，丢失跨会话身份，且缺乏对替代或矛盾的第一类概念。WorldDB 提出向量图世界记忆引擎，通过本体感知的写入时 reconcilation 机制，实现跨会话的身份保持和矛盾检测。该工作为构建具有连续记忆的长周期智能体提供了基础设施层面的创新。

### 7. RAG 系统中多跳推理评估：LLM 基检索器评估策略比较
**URL:** https://arxiv.org/abs/2604.18234v1  
**发布:** 2026-04-20 | **分类:** cs.IR, cs.AI

**解读:** RAG 系统通过外部知识增强 LLM 的回答准确性，但针对 RAG 系统（尤其是检索器组件）的评估研究仍然有限。本文系统比较了多种 LLM 基检索器评估策略在多跳推理场景下的表现，揭示了不同评估方法的相关性和局限性。研究结果为构建更可靠的 RAG 评估框架提供了实证依据，对 RAG 系统的优化和选型具有指导价值。

### 8. SafetyALFRED: 评估多模态大语言模型的安全意识规划能力
**URL:** https://arxiv.org/abs/2604.19638v1  
**发布:** 2026-04-21 | **分类:** cs.AI, cs.CL, cs.RO

**解读:** 多模态大语言模型正被越来越多地用作交互式环境中的自主智能体，但其主动应对安全隐患的能力仍显不足。作者在 ALFRED 具身智能体基准基础上，增加六类真实世界安全隐患场景，构建 SafetyALFRED 评估框架。实验表明当前 MLLM 在安全规划方面存在显著缺陷。该工作为开发更安全的具身智能体提供了评估工具和基线数据，对 AI 安全研究具有重要价值。

## 🔬 可实验假设（2-3 条）

1. **不确定性量化提升 Web 智能体鲁棒性**: 在自建 Web 自动化任务中，引入 WebUncertainty 的双层级不确定性机制，对比基线智能体在长周期任务（>10 步）中的成功率变化。预期不确定性驱动的动态规划可将失败率降低 30% 以上。

2. **MASS-RAG 在噪声检索场景的优势**: 使用自建含噪声检索数据集（人工注入 20-40% 无关文档），对比 MASS-RAG 与传统 RAG 在问答准确率上的差异。预期在多智能体合成机制下，准确率提升可达 15-25%。

3. **显式问题建模减少规划幻觉**: 在复杂规划任务（如多约束调度）中，对比"模型优先"框架与标准 CoT/ReAct 的约束违反率。预期显式建模可将约束违反率从 40%+ 降至 15% 以下。
