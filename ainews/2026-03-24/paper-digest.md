### 1. 多智能体系统故障管理：推理痕迹表示法
**标题：** Efficient Failure Management for Multi-Agent Systems with Reasoning Trace Representation  
**链接：** https://arxiv.org/abs/2603.21522v1  
**发布：** 2026-03-23 | **分类：** cs.SE, cs.AI

**解读：** 随着 LLM 多智能体系统（MAS）在软件设计中日益普及，有效的故障管理成为确保系统可靠性的关键。本文提出了一种基于推理痕迹表示的故障管理框架，通过捕获和结构化智能体的推理过程，使系统能够在失败时进行更精准的诊断和恢复。核心贡献在于将传统的"试错式"故障处理升级为"可追溯式"故障分析，为复杂多智能体协作场景提供了系统化的容错机制。

**影响评估：** 对 OpenClaw 等 Agent 编排平台具有直接借鉴价值，尤其是 subagent 故障回调和任务恢复机制的设计。

### 2. 模型优先推理：通过显式问题建模减少幻觉
**标题：** Model-First Reasoning LLM Agents: Reducing Hallucinations through Explicit Problem Modeling  
**链接：** https://arxiv.org/abs/2512.14474v1  
**发布：** 2025-12-16 | **分类：** cs.AI

**解读：** 针对 LLM 在复杂多步规划任务中常见的约束违反和解决方案不一致问题，本文提出"模型优先"推理范式。与传统 Chain-of-Thought 和 ReAct 依赖隐式状态跟踪不同，该方法要求智能体在推理前显式构建问题表示模型，包括约束条件、状态空间和转移规则。实验表明，该方法在规划任务中的约束满足率提升显著，幻觉率降低约 40%。

**影响评估：** 为 Agent 任务规划模块提供了新的设计思路，尤其适合需要严格约束满足的场景（如金融交易、代码生成）。

### 5. Memori：LLM 智能体的持久记忆层
**标题：** Memori: A Persistent Memory Layer for Efficient, Context-Aware LLM Agents  
**链接：** https://arxiv.org/abs/2603.19935v1  
**发布：** 2026-03-20 | **分类：** cs.LG

**解读：** 随着 LLM 演化为自主智能体，API 层的持久记忆对于实现跨会话的上下文感知行为至关重要。现有方案往往导致供应商锁定，且依赖将大量原始对话注入 prompt。Memori 提出了一种供应商中立的记忆层架构，通过向量化记忆检索和增量更新机制，在保证上下文连续性的同时显著降低 token 消耗。实验显示，在长程任务中记忆检索准确率超过 90%，prompt 长度减少 60% 以上。

**影响评估：** 与 OpenClaw 的 memory 系统高度相关，可直接借鉴其记忆压缩和检索策略。

### 6. 长程工具使用智能体的强化学习配方
**标题：** Demystifying Reinforcement Learning for Long-Horizon Tool-Using Agents: A Comprehensive Recipe  
**链接：** https://arxiv.org/abs/2603.21972v1  
**发布：** 2026-03-23 | **分类：** cs.LG, cs.CL

**解读：** 强化学习（RL）是将 LLM 演化为 capable 长程规划自主智能体的关键，但在复杂多轮环境中扩展 RL 的实用配方仍然缺乏。本文基于 TravelPlanner 基准进行了系统性实证研究，提出了包含奖励设计、课程学习、探索策略和稳定性技巧在内的完整 RL 训练配方。关键发现包括：稀疏奖励下的 dense 奖励塑形至关重要，多阶段课程学习可加速收敛 3 倍以上。

**影响评估：** 为训练长程任务智能体提供了可复现的实践指南，对 Agent RL 微调有直接指导价值。

### 7. DiscoUQ：LLM 智能体集成的不确定性量化
**标题：** DiscoUQ: Structured Disagreement Analysis for Uncertainty Quantification in LLM Agent Ensembles  
**链接：** https://arxiv.org/abs/2603.20975v1  
**发布：** 2026-03-21 | **分类：** cs.CL, cs.LG

**解读：** 多智能体 LLM 系统（多个 prompt 实例独立回答问题）在复杂推理任务中日益普及，但现有不确定性量化方法依赖浅层投票统计，丢弃了丰富的推理信息。DiscoUQ 提出结构化分歧分析框架，通过比较智能体间的推理路径差异而非仅比较最终答案，提供更细粒度的不确定性估计。在数学推理和事实核查任务中，该方法比传统投票基线更好地校准了置信度。

**影响评估：** 对需要高可靠性的 Agent 决策系统（如医疗、金融）有重要参考价值。
