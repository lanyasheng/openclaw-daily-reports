## 第一部分：本周最重要 10 条

**1. OpenAI Skills Catalog 正式发布，一周狂揽 12,980 星** [openai/skills](https://github.com/openai/skills)  
OpenAI 官方 Codex 技能目录开源后爆发式增长，从周初 582 星飙升至周末 12,980 星。Skills Catalog 为 Codex 提供标准化技能注册和发现机制，与 OpenClaw Skill 体系形成直接对标。这验证了"技能市场"模式的可行性，预计将吸引更多框架跟进类似设计。对于一人公司而言，技能复用和生态建设将成为 Agent 开发的核心竞争力。

**2. Anthropic 发布 Claude Code 企业版，支持 VPC 私有化部署** [Anthropic Blog](https://www.anthropic.com/news/claude-code-enterprise)  
Claude Code 企业版支持 VPC 私有化部署、审计日志、自定义 retention 策略，关键突破是"air-gapped"完全离线部署能力。这是对 GitHub Copilot Workspace 和 Cursor Business 的直接回应，满足金融/政府客户的合规需求。企业级 AI 部署进入"合规优先"阶段，能否满足合规要求将决定 2026 年市场份额。

**3. MCP 协议 2.0 草案发布：支持双向流式传输** [Model Context Protocol](https://modelcontextprotocol.io/specification/2026-03-05)  
MCP 2.0 新增服务器到客户端的主动推送能力、双向流式传输、会话状态管理，从"请求 - 响应"模式升级为事件驱动架构。这意味着 MCP 服务器可以主动通知客户端事件（如文件变更、任务完成），对 Agent 实时响应能力是重大提升。协议可能催生基于 MCP 的 Agent 协作网络，类似去中心化的 Agent 互联网。

**4. Claude Code 成本结构曝光：$200 收费 vs $5000 计算成本** [The Decoder](https://the-decoder.com/anthropics-claude-code-subscription-may-consume-up-to-5000-in-compute-per-month-while-charging-the-user-just-200/)  
Cursor 内部分析披露：Anthropic 的$200/月 Claude Code 订阅，实际消耗计算成本高达$5000/用户/月，每位用户补贴$4800。这揭示了 AI 编码助手定价与成本的巨大鸿沟，模式可持续性存疑。可能推动行业向"基础功能免费 + 高级功能付费"或"按使用量计费"模式转型。

**5. 阿里巴巴开源 OpenSandbox：AI 应用沙盒平台** [alibaba/OpenSandbox](https://github.com/alibaba/OpenSandbox)  
OpenSandbox 是通用 AI 应用沙盒平台，提供多语言 SDK、统一沙盒 API 和 Docker/Kubernetes 运行时，支持 Coding Agents、GUI Agents、Agent 评估、AI 代码执行和 RL 训练。关键特性包括 gVisor/Kata Containers/Firecracker 强隔离运行时、统一网络策略、沙盒生命周期管理。这是企业级 Agent 部署的关键基础设施，解决了代码执行安全和环境隔离的核心问题。

**6. 字节开源 DeerFlow 2.0：SuperAgent Harness** [bytedance/deer-flow](https://github.com/bytedance/deer-flow)  
DeerFlow 2.0 是 ground-up 重写的超级 Agent 编排框架，协调 sub-agents、memory、sandboxes 执行分钟到小时级任务。新增 InfoQuest 智能搜索工具集、Claude Code 集成、长时记忆和上下文工程。2 月 28 日发布后登顶 GitHub Trending，展示了从 Deep Research 到 Super Agent Harness 的演进路径。

**7. AI 对冲基金 virattt/ai-hedge-fund 持续热门，总星 46,707** [virattt/ai-hedge-fund](https://github.com/virattt/ai-hedge-fund)  
该项目实现完整的 AI 对冲基金团队架构，包括多代理协作、策略生成、风险控制等模块，本周从 82 星增长至 46,707 星。持续高热反映量化交易领域对 AI Agent 的强烈需求。对于 trading agent 角色，此项目提供了可参考的多代理协作模式和市场分析框架。

**8. Hugging Face 推出 Agent Hub：一站式 Agent 发现平台** [Hugging Face Blog](https://huggingface.co/blog/agent-hub)  
类似 Model Hub 的 Agent 版本，支持按功能、框架、许可证筛选，内置运行时测试沙箱，已收录 2000+ 开源 Agent。平台提供标准化评估基准，帮助用户对比不同 Agent 的性能和可靠性。这标志着 Agent 生态从"分散发布"走向"集中发现"，降低用户采用门槛。

**9. LangSmith 推出 Skills + CLI，让 Coding Agent 自主调试追踪** [LangChain Twitter](https://nitter.net/LangChain/status/2030770765558321504#m)  
LangChain 发布 LangSmith Skills 配合 CLI 工具，使 Coding Agent 能够原生地在终端中调试追踪、创建数据集和运行实验。这标志着 Agent 工程生命周期正由 Agent 自身驱动改进，而非依赖人工干预。对于一人公司，这是降低 Agent 运维成本的重要工具。

**10. Karpathy 提出 Agent 异步大规模协作研究新范式** [Karpathy Twitter](https://nitter.net/karpathy/status/2030705271627284816#m)  
Andrej Karpathy 认为自动研究的下一步应是异步大规模协作（类似 SETI@home），让成千上万个 Agent 在不同研究方向上并行贡献。现有 Git 分支模型已不足以支撑这种协作模式，需要新的抽象层来积累智能成果。这可能是 AI 原生科研协作的早期信号。
