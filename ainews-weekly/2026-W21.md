### 1. DeepSeek 将 75% 折扣永久化，输出 token 价格仅为 GPT-5.5 的 1/34
[The Decoder](https://the-decoder.com/deepseek-makes-its-75-percent-discount-permanent-pricing-output-tokens-at-least-34x-below-gpt-5-5/)

DeepSeek 宣布将 V4-Pro 的 75% 折扣永久化，每百万输入 token 仅 $0.435，输出价格比 GPT-5.5 低 34 倍。在 Agentic AI 场景下（多轮推理消耗大量 token），这一价格差将深刻影响企业模型选型。DeepSeek 虽在绝对性能上落后 GPT-5.5/Opus 4.7，但"足够好+极低成本"的策略正切中 Microsoft 取消 Claude Code 许可、Uber 4 个月烧光全年 AI 预算后的企业痛点。模型层 commoditization 加速，Agent/MCP/Skill 应用层差异化价值更加凸显。

### 3. 代码知识图谱双雄：codegraph 19K 星 + Understand-Anything 21K 星

### 5. Anthropic MCP 隧道：私有 Agent 安全访问企业内部系统
[InfoQ 中文](https://www.infoq.cn/article/jvoDNDaa2bRzwrHQy7lT)

Anthropic 发布 MCP Tunnel 功能，允许 Claude 等私有 Agent 通过加密出站连接访问企业内部系统（数据库、API、内部工具），无需暴露公网。同时推出自托管沙箱，支持在客户基础设施上运行工具执行。这解决了企业部署 AI Agent 最大的安全顾虑——如何让 Agent 安全触达内网资源。MCP 隧道 + 自托管沙箱 + Chrome DevTools MCP 三大里程碑，标志着 MCP 从"协议"变为"平台"。

[MarkTechPost](https://www.marktechpost.com/2026/05/22/microsoft-releases-fara1-5-a-family-of-browser-computer-use-agents-4b-9b-27b-that-outperform-openai-operator-and-gemini-2-5-computer-use-on-online-mind2web/)

### 7. Cloudflare × Stripe Agent 自主部署协议：AI Agent 从辅助到自主执行
[InfoQ 中文](https://www.infoq.cn/article/TbgvhdcciqULlEEmFBbU)

Cloudflare 与 Stripe 联合推出协议，允许 AI 智能体自主创建云账户、开通付费订阅、注册域名并部署到生产环境，无需人类访问仪表盘。人类把关点集中在法律/金融环节（身份验证、服务条款、账单设置），纯技术工作全部由智能体处理。这是 Agent 经济的基础设施级突破——Agent 可以直接完成从注册到上线的全流程。协议是开放的，任何平台都可作为"编排器"。

### 8. Agent 记忆基础设施爆发：TencentDB Agent Memory + GBrain + AgentMemory
[MarkTechPost](https://www.marktechpost.com/2026/05/23/tencent-open-sources-tencentdb-agent-memory-a-4-tier-local-memory-pipeline-for-ai-agents/) | [GitHub: rohitg00/agentmemory](https://github.com/rohitg00/agentmemory)

TencentDB Agent Memory（MIT 协议）提供四级本地记忆管道：符号短期记忆、长期记忆持久化、语义检索层、元管理层自动淘汰。GBrain（Garry Tan 开源）为 Agent 提供自连接记忆层，解决每次会话从零开始的问题。AgentMemory（16.9K 星）定位"AI 编码 Agent 的持久化记忆"。Agent 系统正从"能跑"进入"跑好"阶段——记忆管理成为刚需基础设施。
