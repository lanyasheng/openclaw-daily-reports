## 🏆 第一部分：本周最重要 10 条

### 1. SpaceX 以 600 亿美元收购 Cursor（Anysphere）
AI 编码工具赛道迄今最大并购案，马斯克不补课直接买课代表。Cursor 作为 Codex/Claude Code 的主要竞品被 SpaceX 战略锁定，AI 编码工具进入巨头整合阶段。
[来源](https://www.infoq.cn/article/D9oPd77E8bEpRvpE7oM4)

### 2. Vercel 开源发布 Eve：「目录即 Agent」新框架
核心设计："每个 Agent 就是一个目录，文件映射能力"。支持持久化执行、沙箱隔离、审批机制。Apache-2.0 开源。对 Agent 框架的可组合性提出全新范式。
[来源](https://www.marktechpost.com/2026/06/17/vercel-releases-eve/) | [GitHub](https://github.com/vercel/eve)

### 3. Perplexity 发布 Brain——Agent 工作记忆系统
不是记住用户偏好，而是记住 Agent 的工作经验——什么有效、什么失败、用户修正了什么。夜间自动学习，构建 Agent 工作上下文图谱。标志着 Agent 记忆从"用户记忆"转向"Agent 工作记忆"。
[来源](https://www.marktechpost.com/2026/06/18/perplexity-launches-brain/)

### 4. NVIDIA ENPIRE：8 个 Codex Agent 驱动机器人舰队实现物理世界 AutoResearch
Agent 第一次从数字世界跨越到物理世界自主研究。发现"物理并行 scaling"效应：8 台机器人并行探索效果远超少量。"机器人秒 > GPU 秒 > Token 消耗"的遥测体系为 Agent 工程化设立了新标杆。
[来源](https://research.nvidia.com/labs/gear/enpire/) | [来源](https://nitter.net/DrJimFan/status/2066921736369766762#m)

### 5. OpenAI Codex 上线「Record & Replay」——演示式编程
用户演示一次工作流，Codex 将其录制成可复用的 Skill。AI 编程从 Prompt Engineering 走向 Demonstration Engineering，与 OpenClaw Skills 理念高度共振。
[来源](https://the-decoder.com/openais-codex-can-now-watch-you-work-once-and-repeat-the-task-forever/)

### 6. MCP 推出企业级 OAuth 方案
零接触企业认证方案，覆盖设备授权到 SSH 代理隧道。MCP 从开发者工具走向企业级应用的核心瓶颈（认证安全）被补齐。
[来源](https://blog.modelcontextprotocol.io/posts/enterprise-managed-auth/)

### 7. AWS Bedrock AgentCore Harness 正式 GA
两次 API 调用即可创建生产级 Agent。Agent 平台化"两步走"范式成为行业标准。
[来源](https://aws.amazon.com/blogs/machine-learning/amazon-bedrock-agentcore-harness-is-now-generally-available-go-from-idea-to-production-grade-agent-in-minutes/)

### 8. Claude Code 引入 Artifacts——团队协作功能
编码结果可转化为交互式 Web 页面，与团队共享，代码更新时自动同步。Claude Code 从单人工具进化团队协作平台。
[来源](https://the-decoder.com/anthropic-brings-artifacts-to-claude-code-letting-teams-share-live-pages-from-coding-sessions/)

### 9. Anthropic 获得 Nobel 奖得主 John Jumper（AlphaFold 核心）加入
John Jumper 离开 DeepMind 加入 Anthropic，Demis Hassabis 公开发推告别。Anthropic 正在系统性吸收顶尖人才，DeepMind 领导力危机加剧。
[来源](https://the-decoder.com/google-deepmind-loses-another-top-ai-researcher-as-nobel-laureate-john-jumper-leaves-for-anthropic/)

### 10. Google Cloud Open Knowledge Format：标准化企业知识文档
将组织中零散知识转变为带 YAML frontmatter 的 Markdown 文件，使 Agent 可统一读取。推动 Agent 知识消费标准化。
[来源](https://the-decoder.com/google-clouds-open-knowledge-format-turns-scattered-docs-into-markdown-files-for-ai-agents/)
